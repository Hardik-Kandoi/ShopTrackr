# ShopTrackr

ShopTrackr is a simple and modern inventory and sales management web application built for small shops and businesses.

It allows users to manage products and stock, record sales, apply discounts, and track revenue and profit through an easy-to-use dashboard and reports.

## Features

* Inventory and stock management
* Sales recording with automatic stock updates
* Cost Price (CP) and Selling Price (SP)
* Support for units like pcs, kg, g, L, ml, and dozen
* Percentage and fixed ₹ discounts
* Revenue and profit tracking
* Interactive sales reports and charts
* Indian currency formatting
* LocalStorage-based data saving

## Technologies

Built using **HTML, CSS, JavaScript, and Chart.js**.

## Getting Started

Clone the repository or download the project files and open `index.html` in a web browser.

```bash
git clone https://github.com/yourusername/shoptrackr.git
```

## Data Storage

ShopTrackr currently stores data in the browser using LocalStorage, so no backend or database is required.
